# IdleGuard

**English** | [简体中文](README.zh-CN.md)

A Windows idle detection and screensaver utility in development. A desktop app is planned to help manage screensaver behavior when your PC is idle.

## Current status

The project is at the prototype stage. A complete desktop app is not yet available.

It currently includes `RawIdleTest.ps1`, a test script that compares Windows system idle time with keyboard and mouse Raw Input idle time, and displays the number of received Raw Input events.

## Planned features

- Detect keyboard and mouse activity and PC idle state.
- Help manage screensaver behavior based on idle state.
- Provide a simple desktop interface.

Features and usage instructions will be updated as development progresses.
