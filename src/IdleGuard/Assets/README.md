# IdleGuard app icon artwork

Generated with the built-in image generation tool; transparent PNG sources.

Design reference: https://learn.microsoft.com/en-us/windows/apps/design/iconography/app-icon-design

AppIcon.full.png: full monitor/hourglass identity, also used on the About page.
AppIcon.small.png: simplified hourglass identity for title bar and notification area.
AppIcon.ico: shell icon; 16, 20, 24, 32 px use the hourglass, 40, 48, 64, 96, 128, 256 px use the full icon. Windows selects the closest available frame for its requested size. Regenerate the ICO using tools/Export-AppIcons.ps1.

## Full artwork prompt

Use case: logo-brand. Asset type: final IdleGuard Windows 11 desktop application icon, full version. Follow Microsoft Windows app icon design guidelines: simple flat objects, straight-on front view, balanced silhouette on a 48x48 design grid, exterior rounded corner radius roughly 2/48, very few layers, subtle one-step analogous color gradient only, legible shapes. Exactly two metaphors: a simple blue desktop monitor occupying lower-left and center; a clear upright cyan/indigo hourglass as the foreground focal point placed at the monitor's UPPER RIGHT CORNER, extending ABOVE and RIGHT of the monitor and overlapping/covering part of its screen/frame. Hourglass should be about half monitor height, with broad solid top and bottom bars, readable pinched waist, simple pale sand triangles, no tiny details. Screen is plain solid medium blue with only a very subtle gradient, no waves, wallpaper or symbols. Flat graphic illustration, no perspective, no extrusion, no glass reflections, no glossy chrome, no glow, no photorealistic lighting, no decorative backdrop, no outer tile, no text or watermark. Limited blue/cyan/navy palette with dark medium and light values for light/dark background legibility. Soft short shadow ONLY where hourglass overlaps monitor. Square image centered with approximately 10% transparent safe margin; truly transparent background.

## Small artwork edit prompt

Edit the reference into the companion SMALL Windows application icon. Remove the entire monitor, its stand, and all its shadow. Keep ONLY the existing upright hourglass motif from the upper right, preserving its exact flat front-facing silhouette, cyan/navy/pale sand palette, broad top/bottom bars and pinched waist. Center that hourglass alone on a square transparent canvas and enlarge to fill about 80 percent of canvas height. Simplify any internal detail for crisp recognition at 16,20,24,32 pixels. Same flat Microsoft Windows app icon design language: minimal soft gradient, no glass reflections, no extrusion, no perspective, no glow or surrounding shadow, no text, no outer tile. Actual transparent background. This is the SAME icon identity as the full monitor/hourglass version, not a new concept.
