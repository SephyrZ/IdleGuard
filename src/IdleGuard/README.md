# Screensaver validation app

This directory contains an unpackaged C# / WinUI 3 x64 application targeting .NET 10. NavigationView hosts Screensaver, Activity & devices, About, and Settings. InputMonitor owns background Raw Input and XInput sources without suppressing normal input. Standard HID buttons and axes are parsed through Windows HID capabilities. The searchable add-device dialog lists other input interfaces and blocks unsupported controls. IdleController handles one request per accepted-input cycle, and ScreenSaverService integrates with Windows. TrayIcon provides open/startup/monitor/exit commands. StartupService registers current-user sign-in startup with --background. AdministratorService requests elevation and waits for the original process to exit during restart. A named mutex and registered message prevent duplicate instances. Language, timeout, monitoring, administrator preference and device rules are saved.

See the root [README](../../README.md) for build/run instructions and [architecture](../../docs/architecture.md) for planned files and responsibilities. Empty directories are tracked with `.gitkeep` files until implementation starts.
