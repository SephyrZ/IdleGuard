# Screensaver validation app

This directory contains an unpackaged C# / WinUI 3 x64 application targeting .NET 10. NavigationView hosts Screensaver, Activity & devices, About, and Settings. InputMonitor is owned by App; its hidden native window receives Raw Input without suppressing normal input. IdleController handles one request per accepted-input cycle, and ScreenSaverService integrates with Windows. TrayIcon keeps the main window alive when hidden and provides open/startup/monitor/exit commands. StartupService registers current-user sign-in startup with --background. A named mutex and registered window message prevent duplicate instances. Language, timeout and monitoring preferences are saved. Game controllers and saved device selection are not implemented yet.

See the root [README](../../README.md) for build/run instructions and [architecture](../../docs/architecture.md) for planned files and responsibilities. Empty directories are tracked with `.gitkeep` files until implementation starts.
