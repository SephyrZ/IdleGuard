# IdleGuard

需要 **Windows 10 2004 或更高版本，x64**。运行上级目录的 `IdleGuard.exe`，无需另装运行环境。首次启动需解压依赖，可能稍慢。

1. 在屏保页设置等待时间，开启监控。
2. 在“监测与设备”中选择哪些输入重置计时；“测试屏保”可手动启动屏保。
3. 关闭窗口后继续在托盘运行；从托盘菜单退出。

首次启动默认请求管理员权限，可在设置中关闭，下次启动生效。已有关闭选择会保留；取消授权仍以普通权限打开。

应用或驱动请求保持显示开启时，自动屏保会延后。这项检查需要管理员权限，失败时暂停自动触发。Windows 自己的屏保计时仍独立工作；在 Windows 屏保设置中选择“无”会关闭系统屏保。

设置提供语言切换和登录自启。配置保存在 `%LOCALAPPDATA%\IdleGuard\settings.json`；移动程序后，请关闭再打开自启以更新路径。

目前为原型版本，部分手柄可能不支持，实体手柄覆盖和登录提权仍需验证。
