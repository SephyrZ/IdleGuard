# IdleGuard

双击上级目录的 `IdleGuard.exe` 启动。无需另外安装 .NET 或 Windows App SDK。

需要 Windows 10 2004 或更高版本（x64）。首次运行会把内含依赖解压到系统的 .NET 缓存，可能比后续启动稍慢。单文件压缩减少的是分发体积，运行缓存仍占用磁盘空间。

## 目录

- `IdleGuard.exe`：程序入口及压缩运行依赖。
- `docs/`：中英文使用说明。

## 使用

主页设置等待秒数，点击开始监控。底部固定栏显示空闲时间、当前时间，以及最近检测到屏保运行的名称和时间。

Windows 屏保卡片可修改系统屏保和等待秒数，修改在后台依次保存，界面可继续操作。行末图标打开系统设置；后台写入完成后，系统应用的修改每 5 秒及切回 IdleGuard 时同步。选择“无”关闭系统屏保。这些设置与上方 IdleGuard 独立计时分开。窗口最小为 660 × 660 逻辑像素。

默认加入键盘、鼠标和支持的手柄。设备页选择哪些输入重置计时，设备选择会跨重启保存。“刷新设备”旁的“添加设备”可以按名称、类型或路径搜索其他 Windows 输入接口；不支持的接口不能添加。设备接口路径默认隐藏，可用列表上方开关显示。

关闭窗口后继续在托盘后台运行。左键托盘图标打开窗口；右键可以切换开机自启、监控屏保，或退出程序。设置页提供中英文切换、开机自启和默认管理员启动偏好。管理员偏好启用后，启动及登录自启时可能需要 Windows 授权；可点击重启按钮立即应用。关闭后下次普通启动生效，Windows 兼容性设置优先。

配置保存在 `%LOCALAPPDATA%\IdleGuard\settings.json`，不放在程序目录内。移动程序后，请关闭再打开开机自启开关，使 Windows 使用新的程序路径。

这是原型版本。手柄使用 XInput 或标准 HID 按键和轴，包含模拟量过滤。XInput 槽位不是稳定的实体手柄身份，厂商专用 HID 可能不支持。实体手柄覆盖和登录时提权仍需验证。
