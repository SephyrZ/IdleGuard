# IdleGuard

[English](README.md) | **简体中文**

一个正在开发中的 Windows 空闲检测与屏保辅助工具，计划提供桌面应用，方便管理电脑闲置时的屏保行为。

## 当前进度

项目处于原型阶段，尚未提供完整桌面应用。

目前包含 `RawIdleTest.ps1` 测试脚本，用于对比 Windows 系统空闲时间与键鼠 Raw Input 空闲时间，并显示收到的 Raw Input 事件数量。

## 开发方向

- 检测键盘、鼠标活动及电脑空闲状态。
- 根据空闲状态辅助管理屏保行为。
- 提供简单易用的桌面界面。

具体功能与使用说明会随开发进度更新。
