# IdleGuard

[English](README.md) | **简体中文**

一个正在开发中的 Windows 工具，通过设备名单维护独立空闲计时，达到超时时间后主动启动系统当前配置的屏保。桌面界面计划使用 C# + WinUI 3。

## 当前进度

项目处于原型阶段，尚未提供完整桌面应用。

目前 WinUI 3 应用已支持左侧导航、键鼠设备选择、独立空闲计时、手动测试、超时自动启动屏保、托盘后台运行和登录自启。设置里可以即时切换中英文。[RawIdleTest.ps1](prototypes/RawIdleTest.ps1) 仍作为独立诊断脚本保留。手柄尚未实现。

## 运行验证窗口

日常使用请打开项目根目录下的 `Release/IdleGuard.exe`。这是压缩单文件版，自带 .NET 与 Windows App SDK 运行环境；目录内仅有程序和 `docs/` 说明文件夹。首次启动会将运行依赖解压到 .NET 缓存，因此分发包体积小于运行时的总磁盘占用。

在 PowerShell 中运行 `./scripts/publish.ps1` 可重新生成本地发布目录，更新前请先从托盘菜单退出正在运行的发布版。脚本只在本地整理文件，不上传或发布 GitHub Release。`bin/`、`obj/` 是开发构建输出，不作为面向用户的发布目录。

需要 Windows 10 2004 或更高版本（x64）、.NET 10 SDK，以及首次构建时访问 NuGet 的网络连接。构建输出自带 Windows App SDK 运行时，无需安装 MSIX。

```powershell
dotnet build src/IdleGuard/IdleGuard.csproj -c Debug -p:Platform=x64
& ./src/IdleGuard/bin/x64/Debug/net10.0-windows10.0.19041.0/win-x64/IdleGuard.exe
```

首次启动默认中文，在“设置 → 显示语言”可以立即切换 English。语言、时间和监控开关保存到 `%LOCALAPPDATA%/IdleGuard/settings.json`。首次启动默认不监控，之后恢复上次保存的开关。

## 页面与自动启动

- **屏保**：选择自定义整数秒数（1–86,400），或读取 Windows 屏保时间。点击“开始监控”建立新计时基线，“暂停监控”停止自动请求。主页显示系统屏保信息；空闲时间、剩余时间和监控状态统一在底部固定栏显示。
- **监测与设备**：查看实时输入、接受/忽略结果，选择键鼠接口。
- **关于**和**设置**固定在左下角；设置提供即时中英文切换和开机自启开关。
- 所有页面右下均保留“测试屏保”，左侧显示精确到秒的当前时间。测试说明放在按钮悬停提示中；检测成功后显示屏保名称及首次检测到运行的本地日期时间（精确到秒，并非精确进程创建时间）。系统配置自动刷新，不再提供手动刷新按钮。

独立计时达到当前采用的时间后，每个空闲周期仅请求一次屏保。选中设备的输入开启新周期；未选设备退出屏保不会立即循环重启。系统屏保已运行时不会重复请求。启动失败或 10 秒内未确认运行，会暂停自动触发，点击“重试监控”后重新开始。修改生效的时间会重建监控基线。读取系统时间不覆盖已保存的自定义值，也不修改 Windows 设置；应用运行中每 5 秒重新读取系统配置。

请求发出不代表启动成功，程序会后台检测最多 10 秒。未配置系统屏保时，测试按钮禁用，自动启动显示错误。

## 设备选择与空闲计时

- 键盘、鼠标接口默认勾选。取消勾选后，该接口输入不重置 IdleGuard 的计时，正常操作电脑不受影响。
- 底部固定栏在每一页显示独立空闲时间和监控状态，当前时间与手动测试屏保按钮位于右侧。监测页显示最近输入、来源设备、接受/忽略结果和事件次数。次数按输入报文统计，不代表用户操作次数。
- 设备默认每项一行，名称后显示连接状态；打开“显示设备接口路径”后，第二行显示 Windows 设备接口路径，默认隐藏。
- 鼠标实际移动、绝对坐标变化、按键变化、非零滚轮变化，以及键盘按下/重复/释放算有效活动。空鼠标报文和无法归属设备的输入不重置计时。
- 通过独立隐藏窗口接收 Raw Input，主窗口最小化时仍监控。锁屏或系统挂起时暂停，解锁或恢复后重新计时。
- “刷新设备”不重置计时。拔出的接口保留在列表并标记离线；本次运行中按设备路径保留选择，相同路径重连可恢复。选择暂不跨应用重启保存，换 USB 口或连接方式可能改变路径。同一实体设备可能显示为多个接口。
- “测试屏保”长期保留为手动测试按钮。Windows 自己的屏保计时仍独立工作。

检查结果与待验证场景见[输入验证记录](docs/input-validation.md)。

## 后台与开机自启

关闭窗口会隐藏到系统托盘，输入监测和自动屏保继续运行。左键托盘图标打开窗口；右键提供“开机自启”“监控屏保”勾选项和“退出”。开关与设置页、主页同步。重复启动程序会唤回现有窗口，不会多开实例。“退出”停止监控并移除托盘图标。

开机自启使用当前用户的 Run 注册表项，在登录 Windows 后以 `--background` 启动当前可执行文件；默认关闭。移动程序位置后，需要在新位置关闭再打开自启开关。Windows 可延迟或通过任务管理器禁用自启，本次验证未重启系统进行登录测试。

## 开发方向

- 接入手柄与死区判断。
- 保存设备选择。

设备名单决定哪些输入能重置 IdleGuard 的计时。屏保启动后的退出与登录要求由 Windows 和屏保处理。系统自己的屏保计时仍独立工作，可能提前触发；IdleGuard 默认不修改它。

具体功能与使用说明会随开发进度更新。
